## Taking part

Suggest a paper, volunteer to lead a discussion, or add to the meeting notes. Suggestions can be brief: a link and a sentence about why it interests you are enough.

Meetings are meant to be informal. We will read / skim the papers in real time and discuss results and figures.

## Editing on GitHub

You only need a GitHub account and an accepted collaborator invitation; no Git installation is needed.

1. Open the file you want to update and click the pencil button.
2. Edit the text, then use **Preview** to check it.
3. Click **Commit changes**, add a short description such as “Suggest a paper,” and select **Commit directly to the main branch**.
4. Click **Commit changes** to save.

Refresh the page before starting an edit so you have the latest version. If GitHub reports a conflicting edit, reload the file and apply your changes to the updated text. File history keeps earlier versions available.

## Adding meeting notes

After each meeting, review and edit the AI-generated notes or transcript, then save them in `meetings/` using the meeting date as the filename (for example, `YYYY-MM-DD.md` or `YYYY-MM-DD.pdf`). Add a link to the file in the [schedule](schedule.md).

To upload an existing file on GitHub, open the `meetings/` folder and choose **Add file → Upload files**. To paste text directly, choose **Add file → Create new file**, name it `YYYY-MM-DD.md`, and paste your edited notes. Save the changes to `main`.
